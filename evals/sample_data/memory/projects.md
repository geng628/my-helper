# 项目开发备忘

## 工具安全规范

外部命令必须使用固定 argv 数组并设置 shell=False，防止命令注入。
敏感目录（如 .env、.git、.ssh）禁止工具读取，写操作只允许落在工作区目录内。

## 插件扩展方式

自定义工具通过 @tool 装饰器声明在 plugins/ 目录下，并在 config/tools.json 的白名单中勾选启用。
插件热插拔无需修改核心 ReAct 循环代码，禁用某个工具只需从 enabled_tools 列表移除即可。

## Atlas 数据同步服务

Atlas 是一个轻量级增量同步服务，部署在东京机房（ap-northeast-1）。
Atlas 网关监听端口定为 9092，本地状态库选用 SQLite 并开启 WAL 模式以支持并发读写。
Atlas 的批处理同步超时上限为 45 秒，失败后采用指数退避重试最多 3 次。

## Nova 遥测采集器

Nova 是面向边缘节点的指标采集器，部署在新加坡机房（ap-southeast-1）。
Nova 上报接口监听端口为 8443，采用标准库 HTTP 长连接按 60 秒窗口批量聚合指标。
