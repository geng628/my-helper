# 个人偏好与日常习惯

## 沟通风格

回复保持简洁分条，代码示例优先使用 Python 标准库。
代码里的函数和类上方写一句简洁中文注释，方便快速阅读。
汇报实验和评测结果时必须同时列出通过项、失败项和未验证项，绝不挑有利案例报喜不报忧。

## 开发环境与工程习惯

本地开发主机使用 macOS 和 zsh 终端，Python 版本统一为 3.12+ 并通过 uv 管理虚拟环境。
生产代码坚持零第三方运行依赖，仅在开发测试阶段引入 pytest。
新功能和 Bug 修复严格遵循 TDD（测试驱动开发）：先写会失败的单元测试确认红灯，再写最小实现跑绿灯，最后做局部重构。

## 工作节奏

上午专注于深度编码与架构设计，下午处理杂务与代码审查。
每周五下午预留两小时复盘本周评测报告和清理技术债务。
