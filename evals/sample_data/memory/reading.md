# 技术阅读与论文笔记

## 记忆评测公开基准

LongMemEval（ICLR 2025）系统评测聊天助手的五项核心长期记忆能力：信息抽取、多会话推理、知识更新、时间推理与拒答防幻觉（Abstention）。
LoCoMo（ACL 2024）聚焦超长多会话对话记忆，包含单跳问答、多跳推理、时间问答、开放领域与对抗拒答五类题目，并精确标注每题对应的对话轮次证据（dia_id）。

## 检索与存储演进笔记

当前纯文本关键词检索适合零依赖冷启动，但在同义改写、中英跨语种查询和长尾词召回上存在天然短板。
下一步检索升级路线是引入 Python 标准库内置的 SQLite FTS5 全文索引与 BM25 相关性排序，并结合中英文分词与时间衰减做混合打分。

## 分布式系统读书摘要

DDIA 第七章强调快照隔离（Snapshot Isolation）可以防止不可重复读与读偏斜，但仍需通过显式锁或可串行化快照隔离（SSI）防范写偏斜（Write Skew）。
